# HPC workspace 0.4.0-preview1

The workspace now has explicit, versioned dotfiles with persistent personal settings. Shared defaults ship in the image; first entry creates only missing starter files under `~/.config/hpc-workspace/`. Existing preferences and symlinks are preserved across image updates and simultaneous starts.

- Customize Bash, Readline, Neovim, and tmux through their personal files in that directory. Git, bat, and Neovim also have a writable application configuration directory under `xdg/`.
- Shared include/loader files keep defaults connected to the selected image. Your edits are never automatically merged or overwritten. Normal host shell/editor configuration is unchanged; Git still reads your usual `~/.gitconfig`.
- The launcher keeps the container's home path aligned with its explicit host-home bind, including when the launching shell uses an alternate home directory.
- Fzf's shell bindings are now included and loaded: Ctrl-R selects history onto the editable command line, Ctrl-T inserts a path, and Alt-C selects a directory. Enhanced Tab completion is initialized, including Git commands.
- Core tool versions retain their existing pins. The broader tool catalog, editor plugins, and custom HPC toolbox remain in the roadmap.

Download the SIF and matching source bundle, plus their `.sha256` files. Follow the [transfer guide](https://github.com/ray12514/hpc-workspace/blob/v0.4.0-preview1/docs/transfer.md) and [dotfile guide](https://github.com/ray12514/hpc-workspace/blob/v0.4.0-preview1/docs/dotfiles.md). Start a fresh workspace after selecting the new image; an existing tmux server retains its loaded settings until explicitly reloaded or recreated.

This remains a Linux amd64 core-development preview. The [validation record](https://github.com/ray12514/hpc-workspace/blob/v0.4.0-preview1/docs/validation.md) documents the local Docker and extracted-SIF checks. Normal SIF mounting on each target remains a site-local check. No cluster access, private system data, AI authentication, or live scheduler submission was used.
