# 0.7.0-preview1: configuration forms and named API gateways

`ws configure` now provides Gum forms for workspace settings and named Codex/Claude Code API gateways. Create several connections, load their current values, review changes, and save. Existing profiles offer key rotation and default selection. Basic prompts are available with `--plain` or `TERM=dumb`.

From the repository checkout in your native Linux shell:

```bash
git pull --ff-only && ./setup
```

Open a new Bash session, enter the workspace, and configure a connection:

```bash
ws enter
ws configure codex team-a
ws agent codex team-a
# Claude has the same workflow:
ws configure claude team-a
ws agent claude team-a
```

Create `team-b` the same way to keep another gateway. Each profile owns its native connection settings and private credential source. Keys are hidden during entry and review, stored in mode-600 files or supplied through a named environment variable, and read again on each new launch. Unrelated settings are retained; saving detects concurrent edits, creates private backups, and replaces files atomically. Native agent configuration remains available through `ws agent TOOL --native`.

Codex requires an OpenAI Responses-compatible gateway; Claude requires an Anthropic Messages-compatible gateway with a supported bearer or API-key header. These forms do not translate protocols or implement general YAML schemas, cloud federation, or automatic key renewal. See the [gateway guide](../agent-profiles.md) for commands, storage, and routing limits.

The native installer also checks and remembers Apptainer during install/update. An absolute executable path is used when sufficient; a required module recipe is loaded in a child process on later launches. `ws runtime setup` retries or overrides discovery, and `ws runtime status` shows the saved selection. Runtime validation is not repeated on ordinary shell entry. See [runtime setup](../runtime-setup.md) for module-based sites and updates started inside the workspace.

This release adds Gum and the private TOMLKit parser to the existing pinned Nix package set. Compiler, editor, scheduler, and scientific-runtime policies are unchanged. Configuration stays local to the system; public acceptance uses synthetic files and credentials. The [validation record](../validation.md) records the completed artifact, terminal, agent-routing, and installer checks and their limits.

The final SIF passes the complete integrated suites under Apptainer **1.3.6 and 1.5.3** using extracted-SIF execution. The matching transfer bundle passes installation, saved-runtime startup without Apptainer on PATH, reinstallation, fresh Bash startup, in-workspace update, and custom startup-file checks. The SIF is **696.0 MiB**. Gum is **2.0.1**; the existing agents remain Codex **0.155.1** and Claude Code **2.1.280**.
