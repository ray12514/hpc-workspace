# HPC workspace 0.1.0-preview1

First preview of the portable Linux amd64 development environment for Ruth (PBS), Jean (Slurm), and Blueback (Slurm).

## Start here

Download the `.sif`, the explicitly named `hpc-workspace-source-0.1.0-preview1.tar.gz` bundle, and both matching `.sha256` files below. Transfer them using your site's approved method, verify the checksums on the cluster, and follow the [transfer and startup guide](https://github.com/ray12514/hpc-workspace/blob/v0.1.0-preview1/docs/transfer.md).

No container registry or Docker installation is required on the cluster. The launcher needs host Python 3.6+ and Apptainer. The runtime target is Apptainer 1.3.6 through 1.5.

## Included

- Ubuntu 24.04 userspace, Neovim, tmux, Git, shell/search tools, Python, Node, compilers, and build/debug tools.
- Codex 0.155.1, Claude Code 2.1.278, and versioned Matt Pocock/Vercel skills. AI clients use your own authentication on approved systems; no credentials are included.
- A shared launcher, generic PBS/Slurm profiles, persistent editor/shell state, checksum-verified image selection, and rollback.
- Installed-package manifests and a release record for the downloadable artifacts. The local Docker archive is not uploaded in this transfer release.

## Validation and scope

Local launcher tests, offline non-root Docker execution, state persistence, and tmux layout recovery passed. The SIF contents passed smoke checks with Apptainer 1.3.6 and 1.5.3 using extraction (`--unsquash`).

Direct nested SIF-mount execution returned `EINVAL` on the local Docker Desktop VM. Normal mounted-SIF execution on the target clusters remains a site-local check. This preview does not establish GPU toolkit, MPI, interconnect, or live scheduler compatibility. See the [complete validation record](https://github.com/ray12514/hpc-workspace/blob/v0.1.0-preview1/docs/validation.md).

Actual site profiles, credentials, job data, and local reports remain on the clusters. This is a personal development environment, not an official HPCMP release.
