# 0.6.1-preview1: normal tmux exit and installer recovery

Closing Bash with Ctrl-D or `exit` previously left tmux displaying a dead pane because the shared configuration enabled `remain-on-exit`. This patch turns that setting off. Finished panes close, the other panes remain usable, and closing the final window returns to the parent shell. Ctrl-C continues to interrupt a command without exiting the shell. The tool versions, Nix lock, and editor configuration are unchanged from 0.6.0.

The [startup guide](../thin-start.md#missing-launcher-or-only-a-skills-directory) now covers a missing `ws` command or a home containing only the workspace skills directory. The standalone installer establishes the runtime without requiring an already installed launcher; skills and personal configuration are preserved. There is no claim that the cause of a particular site's earlier missing installation has been identified.

Transfer and verify the SIF, source archive, installer, manifest, and checksums together. When `ws` is available:

```bash
ws update /path/to/release-0.6.1-preview1.json
```

When it is unavailable, run from the transferred release directory in the native login shell:

```bash
python3 install-workspace-0.6.1-preview1.py release-0.6.1-preview1.json \
    --prefix "$HOME/.local/share/hpc-workspace/runtime"
source "$HOME/.local/share/hpc-workspace/runtime/activate.sh"
hash -r
```

Use `--shell-startup FILE` with the actual site-loaded startup file when needed. Start a fresh `ws session` from the native shell afterward. Existing sessions retain their original configuration, and personal tmux overrides continue to take precedence.

The local regression drives the actual packaged tmux through a terminal: it reproduces a dead pane with the previous configuration and checks Ctrl-C, Ctrl-D, `exit`, multiple panes, and return from the final attached client with the fix. The managed session check also closes all windows normally and waits for its container keeper to finish. Artifact and installer results are recorded in the [validation record](../validation.md). No target cluster or private site data was accessed.

All 58 Linux unit tests pass. The final SIF passes the complete integrated suites under Apptainer **1.3.6 and 1.5.3**, using extracted-SIF execution. The actual standalone bundle also passes installation from a skills-only home, preservation of existing skills and configuration, fresh Bash startup, reinstallation, and in-container updates with both normal and custom startup files. The SIF is about **691.3 MiB**; all eight uploaded assets have verified sizes and SHA256 hashes.
