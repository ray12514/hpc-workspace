# 0.6.0-preview1: editor and daily toolkit

This preview expands the integrated thin development environment while continuing to use native host files, modules, scheduler clients, and compilers.

- Includes Codex and Claude Code, without credentials or an automatic API session. Agent versions follow workspace releases.
- Adds delta, lazygit, ncdu, Superfile (`spf`), offline tldr pages, just, uv, Ruff, yq, Miller, lnav, direnv, watchexec, hyperfine, btop, difftastic, htop, ShellCheck, and shfmt.
- Preconfigures Neovim with Treesitter parsers, fzf-lua, which-key, gitsigns, completion, manual formatting, Python/Bash/Fortran language servers, and navigation between Neovim and tmux panes. No plugin or parser download is needed at startup. C/C++ uses host `clangd` when available.
- Creates workspace, editor, and agents tmux windows. Ordinary-font defaults work without Nerd Font icons.
- Supplies the Nix runtime's matching locale archive, preserves valid locale settings, and falls back for unavailable names before starting Bash.
- Adds `ws tools` to inspect installed versions and `ws job-env -- COMMAND ...` to remove workspace-only environment settings before invoking a native job client. Scheduler arguments and exit status pass through unchanged.

Transfer the SIF, source archive, installer, manifest, and checksums from the release. Existing installations can select it with:

```bash
ws update /path/to/release-0.6.0-preview1.json
```

Start a fresh `ws enter` or `ws session` afterward. Running sessions keep their old image, including its locale configuration. Personal dotfiles and remembered Bash startup locations survive the update. `ws rollback` selects the previous installed release for new sessions.

For an interactive job, keep tmux on the login node, use the site's usual interactive command (optionally prefixed with `ws job-env --`), then run `ws enter` in the compute-node shell. Processes do not migrate between nodes. Compute-node API connectivity and authentication must be tested locally.

Local validation passes all 58 Linux unit tests, the final SIF's integrated suites under Apptainer **1.3.6 and 1.5.3** using extracted-SIF execution, and the transfer bundle's installation/update checks with both ordinary and custom startup files. The SIF is about **691.3 MiB**. Real cluster execution and AI authentication/API access remain untested here.

See the [startup guide](../thin-start.md), [editor and agent guide](../editor-and-agents.md), and [validation record](../validation.md) for commands, configuration details, and the limits of the local fixtures. No target cluster or private site data was accessed.
